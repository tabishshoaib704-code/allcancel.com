# Qudrat Essential by Faris — Herb E-Commerce Site (Pakistan)

A single-page animated storefront selling herbs/jari booti in Pakistan.

## Files
- `index.html` — the site
- `styles.css` — styling & animations
- `script.js` — product data, cart logic, animations

## Features
- Product grid with category filters (seeds, roots, leaves, wellness blends)
- Animated "fly to cart" add-to-cart interaction
- Slide-in cart drawer with quantity controls, persisted via localStorage
- WhatsApp checkout with a pre-filled order summary (cash on delivery)

## Edit your details
- WhatsApp number: search `923001234567` in `index.html` / `script.js`
- Products & prices: edit the `PRODUCTS` array in `script.js`
- Contact info: edit the `#contact` section in `index.html`

## Deploy
Static site — drag the folder into Netlify Drop, or connect the repo to
Vercel / Cloudflare Pages / GitHub Pages.
